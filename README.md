# Agenda do Campo

App para telemóvel que diz, para cada dia, o que **podar**, **tratar**, **plantar** e **estacar**, segundo o mês e a fase da lua (tradição popular). Calendário para Portugal continental.

## Instalar no Android
1. Abra https://joaoseabramail-alt.github.io/agenda-do-campo/ no Chrome.
2. Toque em ⋮ → **Instalar app** (ou *Adicionar ao ecrã principal*).

Depois de instalada, funciona sem internet.
